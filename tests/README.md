#  Practical Test Scenarios

This folder contains **real-world test cases** based on the functional requirements of the application. 

### 🎯 Objective
To ensure a seamless user experience by testing both common user paths (Happy Paths) and potential error conditions (Negative Testing).

### 📂 Folder Structure
- **Manual/Functional**: Step-by-step guides for core features (Login, Profile, Search).
- **Manual/Edge-Cases**: Scenarios for unusual but possible user behaviors (Large file uploads, session timeouts).

### 🛠️ Methodology
Each test case is designed using **ISTQB principles**, including clear preconditions and verifiable expected results.
